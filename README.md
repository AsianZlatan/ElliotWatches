# Elliot Watches — закрытый складской реестр

Премиальный светлый интерфейс складского учёта для публикации через GitHub Pages. В реестре доступны поиск, фильтры, сортировка, сеточный и списочный режимы, пагинация, сводка и подробная карточка позиции.

Все позиции используют нейтральные CSS-силуэты часов: в проекте нет фотографий и внешних ссылок ANDIOT.

## Как опубликовать

1. Создайте на GitHub новый репозиторий, например `ew-stock-register`.
2. Загрузите в него **всё содержимое этой папки**, включая скрытую папку `.github`.
3. Откройте в репозитории `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите `Source` → `GitHub Actions`.
5. Откройте вкладку `Actions` и дождитесь завершения процесса `Deploy EW register to GitHub Pages`.

После публикации адрес будет иметь вид:

```text
https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/
```

Каждое последующее изменение ветки `main` будет публиковаться автоматически.

> Важно: обычный GitHub Pages не делает этот реестр закрытым. Надпись «Закрытый доступ» является частью интерфейса, а не авторизацией. Не публикуйте конфиденциальные складские данные в открытом доступе.

## Локальный запуск

Требуется Node.js 22 или новее.

```bash
npm ci
npm run dev
```

Откройте адрес, показанный в терминале.

## Проверка статической сборки

```bash
npm run build
```

Готовые статические файлы появятся в папке `out`.

## Где менять содержимое

- `app/page.tsx` — интерфейс, сводка, поиск, фильтры и подробная карточка;
- `app/globals.css` — премиальный светлый адаптивный дизайн и нейтральные силуэты часов;
- `app/inventory-a.json` и `app/inventory-b.json` — данные складских позиций;
- `app/layout.tsx` — название, описание и корневой макет сайта.
